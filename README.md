## 📌 Sobre o Projeto

Este projeto realiza uma análise exploratória e visual dos preços de combustíveis no Brasil entre 2015 e 2024, investigando variações temporais, diferenças regionais e a relação entre inflação e preços.

---

## ❓ Perguntas Orientadoras

- Quais estados possuem combustíveis mais caros?
- Qual combustível apresentou maior aumento?
- Existem diferenças regionais relevantes?
- Há períodos de maior instabilidade?
- Existe relação entre inflação e preços de combustíveis?
